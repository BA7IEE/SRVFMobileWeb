# 接线准备包

阶段：本地前端 + 离线协议；真实传输、测试部署、真实身份、生产发布全部 NOT_RUN。

路由使用 Hash，base 为 `./`，业务组件只用命名路由。正式 frontend origin / API origin 均留待批准，不填真实地址。候选方式为同源反代 `/api/` 或显式允许源的跨域方案；任何方案都需真实 HTTPS 与认证设计确认，不能只换 URL 就给队员使用。

普通包与模拟包使用独立产物目录。演示身份、fixture、场景和二维码不进入普通包；没有运行时查询参数或存储开关。未来 api 配置失败必须停止，不能回退 mock。合成资料不迁入真实库。

本地预览返回实际 CSP 响应头，构建包 connect-src none；开发 HMR 只允许本机。模板见 deploy/nginx.conf.example。模板不代表已经部署；未来启用真实传输时必须按批准 origin 修改 CSP 并重新检查。source map 不公开。index 不缓存，带 hash 资源长缓存；二维码不缓存。chunk 失效只提示刷新，有未保存/结果未知上下文时不自动无限 reload。

兼容记录包括前端提交、后端精确SHA、contracts/manifest.json摘要与解析器版本；不使用 latest 作为部署证据。固定快照为源码切片，没有声称取得 OpenAPI 或生成全量 App SDK。check:contract 仅核对本地来源和摘要，不拉远程main。
