# 集中校验规则

代码入口：src/shared/validation/index.ts；字段规则独立于 Vue，真实资格与认定来自数据源。

| 对象      | 已实施规则                                                                                                           |
| --------- | -------------------------------------------------------------------------------------------------------------------- |
| 登录      | 账号 trim 后 3—32 位字母、数字、下划线、中横线；密码仅非空，不 trim、不改变大小写                                    |
| 修改密码  | oldPassword 非空；newPassword 8—128 位且含字母数字；二次一致。固定 users.dto 的 ChangeMyPasswordDto 证据见契约       |
| 保险      | 公司、保单 1—128 字；允许字母、中文；起保可空；日期合法，起保不晚于到期；携带 expectedVersion，修改回待审核          |
| 动态题    | 短文/长文长度；number 有限并保留 0；日期含闰年检查；单选白名单；多选去重与数量；file 本地初筛；confirmation 明确勾选 |
| 场次岗位  | 至少一场、不重复；岗位属于该场次；岗位志愿顺序显式保存，无岗位不造虚拟岗位                                           |
| 附件      | JPEG/PNG/WebP/PDF；非空且不超过 10 MiB，MIME 与后缀初筛；仅内存预览与对象 URL，不冒充已上传                          |
| 身份/权限 | 全局准入与活动职责分开；allowed/denied/unknown/unavailable 四态；未知禁止乐观放行                                    |
| 日期数字  | 北京业务时间固定 Asia/Shanghai；YYYY-MM-DD 与时间戳分开；null 不显示为0；Decimal字符串原精度保留                     |
| 返回目标  | 只允许已知本站路由与 ID 字符；拒绝外链、协议相对、编码绕过、控制符、未知路径；最终仍受活动权限判断                   |
| 动态键    | 拒绝 **proto**/constructor/prototype 与非法字段；无 eval、动态模板或未清洗 HTML                                      |

首次打开不铺满错误；提交与失焦校验。提交失败保留当前可安全保留输入，首个错误附近滚动。保险版本冲突保留编辑输入，刷新当前记录后人工核对。文件安全与保险有效性仍需正式服务端校验，前端格式检查不是安全认证。
