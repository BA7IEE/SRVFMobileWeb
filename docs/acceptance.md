# 人工验收脚本

先运行 pnpm install、pnpm dev。只使用页面列出的合成身份。右侧场景面板属于测试控制，普通队员页面没有保险审核按钮。

| 步骤 | 操作                                          | 必须观察到                                              |
| ---- | --------------------------------------------- | ------------------------------------------------------- |
| 1    | 未登录打开 /activities/act-open；选择A并登录  | 返回原活动，不能以任意非空输入登录                      |
| 2    | 活动详情→报名→选择场次、明确确认→提交         | 确认对话框；报名已提交（演示）；具体场次结果另列        |
| 3    | 我的活动→多日演练                             | 上午通过、下午候补；只有正确场次显示考勤入口            |
| 4    | 选INS-MISSING，报名页先勾场次→去保险→新增     | 新增后待审核，返回原报名恢复草稿且仍不可提交            |
| 5    | 场景面板“测试控制：保险审核通过”→重新读取     | 资格重新取得后才可报名，不因访问过保险页就放行          |
| 6    | 换B→我的保险                                  | 有统保、无自购，不要求重复登记                          |
| 7    | A报名后进本场次→预置码→签到→立即签退          | 签到回执与当前在场一致；未到允许签退时间拒绝            |
| 8    | 推进时钟30分钟→重读→签退                      | 当前不在场且有历史记录；正式时长仍待认定                |
| 9    | 报名协办访问考勤 / A职责访问其他活动          | 明确拒绝；只负责考勤者反向访问报名也拒绝                |
| 10   | 双职责进入报名管理，选A和C批量审核            | 成功与失败逐项显示，C失败不被算成全部成功               |
| 11   | 考勤协办→核验人员→无原因代签→补原因           | 无原因被挡；对话框含活动/场次/人员/动作；回执后名单一致 |
| 12   | 签到/签退码分别生成、重签、撤销               | 动作明确，版本更新；旧码、错场次与成员码不能混用        |
| 13   | INS-08→修改保单                               | 版本冲突先刷新，保留安全输入，不默认覆盖                |
| 14   | REG-06→提交→查询原结果→刷新我的活动           | 未知结果禁止再提交；最终只一条原报名                    |
| 15   | 复杂表单选文件→移除/重选/刷新                 | 提示本地未上传，支持合法格式；刷新后需重新选择          |
| 16   | 未保存输入→返回/保险/退出/切换账号            | 合理离开提醒；原账号内容不在另一账号后退页面出现        |
| 17   | 场景STAFF-06或服务失败                        | 清除受限内容或显示可重试错误，不无限加载                |
| 18   | 参与记录的待认定、零、更正后结果              | null与0区分，不计算打卡时差或累加原始正分录             |
| 19   | /dev/components及320/375/390/430宽度          | 主按钮、Tab、focus、弹层救援红；无横滚/遮挡             |
| 20   | pnpm build + preview，尝试 ?mock=1 与存储开关 | 只看到未接线；无演示身份、场景、业务提交                |

自动化截图和网络证据见 evidence。桌面实际排版可检查；手机软键盘、锁屏/来电、iPhone/微信相机和HTTPS链路属于真机项目，当前 NOT_RUN。相机权限永不选择时可关闭，晚到流会停止；定位不需要时不申请，超时/拒绝不伪造0坐标。

验收记录使用 PASS / FAIL / NOT_RUN / BLOCKED。不得把静态截图或mock全绿写成真实业务、服务端授权或设备验收完成。
