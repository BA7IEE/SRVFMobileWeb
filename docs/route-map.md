# 路由与页面

本地 Hash 路由；页面名与 API 路径分开。普通业务页需身份有效、成员可用；负责人页还需本活动对应职责。

| 编号 | 页面           | 路由                                                     | 底部导航 | 已实施内容                                       |
| ---- | -------------- | -------------------------------------------------------- | -------- | ------------------------------------------------ |
| U01  | 登录           | `/login`                                                 | 无       | 表单、模拟身份、错误、过期返回、演示提醒         |
| U02  | 活动列表       | `/activities`                                            | 活动     | 搜索、筛选、分页、空态、失败重试、列表记忆       |
| U03  | 活动详情       | `/activities/:activityId`                                | 无       | 场次、岗位、规则、保险提示、本人状态和上下文动作 |
| U04  | 活动报名       | `/activities/:activityId/register`                       | 无       | 动态题、场次岗位、文件选择、草稿、确认和提交回执 |
| U05  | 我的活动       | `/my/activities`                                         | 我的活动 | 本人报名结果、逐场次展示、签到入口、历史摘要     |
| U06  | 扫码考勤       | `/activities/:activityId/sessions/:sessionId/attendance` | 无       | 扫码状态、定位状态、签到签退回执、失败恢复       |
| U07  | 我的参与记录   | `/my/participation`                                      | 无       | 正式／处理中区分、活动场次记录、时长贡献展示     |
| U08  | 我的保险       | `/my/insurance`                                          | 无       | 自购与统保分区、审核和日期状态、添加修改入口     |
| U09  | 我的           | `/my`                                                    | 我的     | 身份摘要、保险、记录、设置、负责人入口、退出     |
| F01  | 我负责的活动   | `/managed/activities`                                    | 无       | 按实际职责显示活动及可进入模块                   |
| F02  | 报名管理       | `/managed/activities/:activityId/registrations`          | 无       | 名单、筛选、允许的审核动作、批量部分失败         |
| F03  | 现场考勤工作台 | `/managed/activities/:activityId/onsite`                 | 无       | 场次选择、签到码／签退码、状态提示与核验入口     |
| F04  | 人员核验与异常 | `/managed/activities/:activityId/onsite/people`          | 无       | 扫成员码、受控代签、必要原因、异常状态与记录     |

子流程：保险新增/编辑、原报名返回、报名逐场次结果、成员码、场次签到/签退码、密码修改、登录帮助、演示协议、403/404/成员不可用/身份暂不可用/未接线。模拟包另有场景面板和 /dev/components，普通包无调试路由。

截图与自动化见 acceptance 和 execution-report。历史摘要与当前详情分开；底部固定为活动/我的活动/我的。
