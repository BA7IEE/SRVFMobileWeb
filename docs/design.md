# 移动端视觉与品牌

固定来源为 `BA7IEE/srvf-admin-web@eaed861acae8fe18b1d12b093c9077060815678b` 的 `src/style/srvf-tokens.scss`，blob 为 `7295d168e2a15e140c5a522456246a6a4736f88d`。原始相关切片保留在 contracts/brand，未导入后台样式、权限工具或认证存储。

设计方案在编码前按移动现场操作复核。采用救援红 `#C4001B` 主操作、盾蓝 `#19478A` 辅助信息、正文 `#0A1426`、次要文字 `#5E6A80`、页面灰 `#F3F4F6` 与白色表面。没有新增队徽，使用 SRVF 文字标识。金色仅保留 token，不用于待审核文字。

中文使用系统字体，标题 22—24px、正文 16px、说明 14px。活动列表用日程式条目；详情按“标题、本人结果、场次岗位、要求、保障”组织；负责人以场次和人员为主要操作对象。界面左对齐，页边距 16px，控件圆角 4px、内容区 8px。没有装饰性大图、远程字体或复杂转场。

主题依次加载 tokens.brand → tokens.mobile → vant-theme → base，并放在全局根，覆盖 Teleport 弹层。状态采用深色文字、彩色标记和明确文案。正常正文与白底的指定色对要求至少 4.5:1；相应数字由 check:tokens 实际计算，未声称整个网站通过 WCAG。

Vant 4.10.2 打包样式含在线图标字体 fallback。Vite 的 `srvf-local-vant-icons` 插件在构建/开发转换中移除此 fallback，只保留包内嵌字体；CSP 只允许 self/data 字体。产物与浏览器网络检查验证没有在线字体尝试。

本地组件预览 `/dev/components` 展示按钮、输入焦点与错误、状态、保险卡、八题长表单、二维码弹层、空/错/未知和操作栏。普通包没有此入口。计算样式由浏览器测试验证，屏宽截图覆盖 320/375/390/430。
